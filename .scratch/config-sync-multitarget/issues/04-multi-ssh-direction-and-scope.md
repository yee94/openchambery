# 04 — 多 SSH 目标、方向选择与白名单组选择

**What to build:** 用户可在多个已就绪 SSH 实例上启动同步，并先选方向：“本地 → 远端”或“远端 → 本地”；每次切换方向后重新计算差异并让用户重新确认范围。范围按配置文件组、完整目录、`.agents` 与凭据勾选，凭据选项受授权通道约束。

**Blocked by:** 02 — 抽出方向无关的同步引擎并迁移 SSH; 03 — 凭据同步授权通道.

**Status:** done
