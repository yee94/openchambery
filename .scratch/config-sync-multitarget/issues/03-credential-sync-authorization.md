# 03 — 凭据同步授权通道

**What to build:** 对目标的访问权限不再隐含凭据传输权限。包含 token 的配置同步（auth.json 等）必须先通过该目标的显式授权：授权在建立连接/配对的信任渠道中完成，可撤销、按目标隔离，并在核心执行层强制生效。

**Blocked by:** 02 — 抽出方向无关的同步引擎并迁移 SSH.

**Status:** done

- [x] 每个同步目标可独立授予/撤销“凭据同步”授权，授权记录按目标身份隔离持久化。
- [x] 授权动作走信任建立渠道完成（配对/实例设置），不是同步向导里的一键勾选。
- [x] 执行层强制：同步计划包含凭据而目标未授权时，预览与执行都拒绝并给出可识别错误；仅隐藏 UI 入口不算达标。
- [x] 凭据默认跳过的既有行为保持；授权只解锁范围，不改变备份与运行记录语义。
