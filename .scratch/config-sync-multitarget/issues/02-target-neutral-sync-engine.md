# 02 — 抽出方向无关的同步引擎并迁移 SSH

**What to build:** managed SSH 实例继续完成配置同步，同时同步计划、目标身份、方向、执行器、分代备份和完成校验形成可复用契约；同一契约既能表达“本地推远端”，也能表达“远端拉本地”，本次只实现推送路径。

**Blocked by:** 01 — 统一同步持久化与运行记录.

**Status:** done

- [x] 每个同步目标拥有稳定、带命名空间的身份，并由目标执行器完成探测、准备、上传和完成校验。
- [x] 计划在源端计算、在目标端执行：契约显式区分源与目标角色，方向是计划的一等字段，反向同步无需改契约即可复用。
- [x] 现有 managed SSH 同步通过新契约完成白名单配置、`.agents` 和显式选择的凭据同步，端到端行为不变。
- [x] 失败运行保留分代备份和可定位的恢复信息，测试覆盖成功、中断与方向字段持久化路径。
