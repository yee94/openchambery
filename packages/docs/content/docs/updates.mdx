# Update the component that needs it

Desktop and mobile expose **Settings → About**. Read which component each version refers to: the installed app, active web bundle, connected Yuri host and OpenCode are not necessarily the same release.

## Follow the offered update type

| The app offers | Your next step |
| --- | --- |
| A compatible OTA update | Apply it and restart/reload when requested. |
| A new desktop installer | Complete the installer flow for the native shell. |
| A required mobile native update | Install the available iOS build or Android APK. |

An OTA cannot add native capabilities missing from an older shell. Updating a phone does not update its remote host.

## Decide the release channel separately

Use the Beta update setting deliberately. A prerelease is not a stable release, even when no stable installer exists yet. The [download chooser](/en/#downloads) labels that case and provides the available platform assets.

## A CLI-hosted installation

Use `yuri update` for the Yuri CLI and follow the selected OpenCode runtime's update guidance separately. If an update fails, record the affected component and error before retrying. Do not delete project data as a client-update repair step.
