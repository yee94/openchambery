# Choose when Yuri interrupts you

Go to **Settings → Notifications**. Enable delivery, then choose the events you want: completion, errors, questions, permission requests, subtasks, scheduled tasks, assistants or goals.

## Match the destination to the device

Desktop alerts use system notifications. Browser delivery has its own permission and background-push controls. Native mobile delivery also depends on the installed app, system permissions and connection state. Enabling an event in Yuri does not override the operating system's notification settings.

Use the test control where it is offered, then verify a real event. A quiet device may be suppressing foreground alerts or notifications at the system level.

## Adjust the message where the editor is available

Desktop, Web and VS Code surfaces expose notification template editing. The native phone app hides that editor and the foreground-alert controls. Use the displayed template fields rather than looking for a message-length setting; no such length control is exposed in the current UI.
