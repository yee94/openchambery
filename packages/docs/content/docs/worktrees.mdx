# Give a task its own checkout

A worktree provides another checkout and branch for the same repository. Use it when concurrent work should not share one set of uncommitted files.

## Start at the project row

For a Git project, use its worktree action in the session sidebar, or choose **New Worktree Draft** from the command palette. On the phone, the project row in the sessions sheet provides the corresponding action. The ordinary project-row control is not offered in VS Code.

Choose the base branch and complete the draft. If GitHub is connected, the creation dialog also offers an existing issue or PR as the starting point. Review the resulting directory and branch before sending the task.

## Finish the branch deliberately

Inspect and commit the work, then use your normal Git or GitHub process to bring it into the destination branch. There is no currently mounted Integrate panel to follow in Yuri.

When removing a worktree, read the cleanup choices carefully: deleting sessions, deleting the directory and deleting branches are distinct operations. Preserve work you still need before choosing them.
