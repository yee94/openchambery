# 在 VS Code 中比较多路运行

当前可创建运行组的入口是 VS Code 的 Agent Manager。桌面和 Web 已不提供原先侧栏中的多模型启动器。

## 从编辑器发起

在 VS Code 打开 Git 工作区，从编辑器命令面板执行 **Yuri: Agent Manager**。创建运行组时填写名称、任务提示词、基础分支和模型，最多选择五路运行，还可以选择 Agent 和 Worktree 初始化命令。

运行组使用编辑器的工作区。创建前检查提示词和分支，尤其留意会修改文件或安装项目依赖的初始化命令。

## 对比实际产物

选择已创建的组，查看各路运行。每路有自己的会话和检出目录。用相同验收条件比较回答和改动；选中一个喜欢的结果，不等于已经合并其分支。

通过常用审查和 Git 流程保留需要的结果。
