# 通过助理安排工作

助理对话和项目会话是两个界面。前者适合讨论安排、协调任务；需要查看执行过程或文件改动时，打开它返回的会话卡片。

## 给联系人一份明确的职责

进入 **设置 → 助理**，新建助理，填写名称、默认提示词、提供商与模型、工作区后保存。工作区可以由系统托管，也可以从已有项目中选择。更换工作区会开始新的助理会话。

例如「帮我维护这个项目的文档，修改公开命令前先询问」，比泛泛的性格描述更容易执行。名称和模型必填；所连接的主机也必须支持并启用助理。

![助理对话和工作卡片](/assets/shots/assistant.webp)

## 沿着卡片跟进

打开 **助理**，选择联系人，发送要求或附上材料。它分配工作后，点击会话卡片进入执行会话。需要引用已经进行的工作时，在助理输入框输入 `@`，选择最近的会话，再说明下一步要求。

计划任务卡片会打开对应任务。请在那里核对时间和提示词，不要仅凭对话里的确认就认定安排完全正确。

## 保留合适的历史

手机连接同一台主机，就能访问同一个助理。要求「开新对话」会重置模型使用的上下文，但保留之前的聊天气泡；要求「清空聊天记录」则会删除之前的记录。请使用符合自己意图的表达。
