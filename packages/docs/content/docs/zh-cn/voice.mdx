# 先说出来，再决定怎样发送

在 **设置 → 语音** 开启输入，并允许正在说话的设备访问麦克风。VS Code 界面不提供语音设置与采集。

## 松手的位置决定操作

手机上按住空白输入框，等待录音开始。中间松手会插入可编辑文字；滑向左侧取消区域会丢弃；滑向右侧发送区域会识别后发送。松手前看清高亮目标。启用后，助理对话也使用这组手势。

桌面上按住输入框录音，松手结束。录音期间 **Enter** 结束，**Esc** 取消。识别后重点检查名称、路径和技术术语。

![桌面录音界面](/assets/shots/asr-desk-close.webp)

## 识别需要一项已配置的服务

| 选择 | 需要准备什么 |
| --- | --- |
| 本地 | Yuri 主机上已下载、支持目标语言的模型。 |
| OpenAI 兼容 | 转写地址、模型和所需凭据。 |
| 火山引擎 / 豆包 | 凭据与流式 ASR 资源，使用麦克风测试。 |

「本地」指主机，不是手机上的离线模型。文件识别测试和实时麦克风测试检查的路径不同。

## 朗读单独配置

在同一设置页选择朗读提供方，再使用消息播放操作。支持的会话也提供自动朗读。没有任何文字就采集失败时，先检查麦克风和浏览器安全环境；能录音但无法识别时，再检查当前主机的服务配置。
