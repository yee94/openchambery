# 理解一段对话的大小

上下文指示器描述发送给模型的对话规模，不代表提供商账户的剩余额度。账户额度应在[用量](/zh-cn/usage/)中查看。

## 打开指示器背后的数字

桌面端点击标题栏的用量环，也可以从命令面板执行 **Show context usage**。Context 面板会显示已用比例、消息数量，以及可取得的 Token、费用和生成速度明细。

这些数字来自报告或计算出的用量，不是订阅剩余额度的保证。明细是否齐全取决于模型返回的数据。

## 对话已经很长时

先判断当前任务还需不需要之前的讨论。希望保留摘要时，使用会话的压缩操作；准备开展不同任务时，整理简短交接后新建会话。重要要求应明确写出，不要完全依赖较早的消息。
