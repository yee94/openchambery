# 结合周期理解账户用量

打开 **设置 → 用量**，选择账户或提供商。这里显示支持的账户额度，不等于某个会话的[上下文用量](/zh-cn/context/)。

## 决定哪些信息常驻

设置侧栏提供刷新、自动刷新间隔和显示偏好。支持的账户详情提供 **在标题栏显示**，方便从标题栏查看，无需反复打开设置。

把用量值、所属周期和重置时间一起阅读。脱离时间窗口的数字容易造成误解。

侧栏的 **Magpie** 分组会发现当前主机上支持的网关，也提供 **连接其他 Magpie** 来填写指定地址。账户聚合和远程访问条件见 [Magpie 集成指南](/zh-cn/magpie/)。

## 区分没有数据与没有额度

能取得哪些明细取决于提供商支持和认证。不可用或请求失败，不代表账户没有剩余额度。先检查错误，需要时重新连接提供商；这里未提供的数字，应到提供商自己的账户页确认。
