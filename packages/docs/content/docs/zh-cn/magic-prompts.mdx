# 调整操作背后的指令

已有操作生成的风格或重点不合适时，使用 **设置 → Magic Prompts**。该页在非 VS Code 界面提供，模板分为 Git、GitHub 和 Session 三组。

## 修改真正需要改变的部分

选择对应操作。模板区分可见文本和指令时，请保留两者的职责：前者展示请求，后者指导执行。不要删除用于填入任务数据的命名占位符。

保存覆盖后，用小例子试一次该操作。模板出现在这里，并不证明所有旧操作仍然拥有可见的启动按钮。

## 恢复原来的行为

重置当前模板会移除该项覆盖。只有确实想放弃整页所有定制时，才使用全部重置。
