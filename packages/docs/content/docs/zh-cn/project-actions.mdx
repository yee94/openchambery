# 随手运行项目命令

启动开发服务、检查构建等需要反复执行的仓库命令，可以保存为项目操作。它执行 Shell 命令，不是给 Agent 发送提示词。

## 在项目配置中定义

打开 **设置 → 项目**，选择项目，编辑 **Project Actions（项目操作）**，给命令起一个明确的名称。启动开发服务的命令还可以配置预览行为。

## 确认操作的是哪个工作区

从标题栏的项目操作图标菜单运行。当前会话或 Worktree 会决定工作上下文；执行破坏性命令前先核对。查看终端输出，判断命令是否真正成功。

输出中有可识别地址时，可以打开预览。远程桌面连接也可能使用 SSH 转发，手机不会自行创建这条隧道。

需要复用的是 Agent 指令而非 Shell 操作时，请创建[命令](/zh-cn/commands-snippets/)。
