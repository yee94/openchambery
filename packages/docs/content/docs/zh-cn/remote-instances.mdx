# 通过 SSH 访问工作空间

SSH 主机管理需要桌面桥接能力。在 **设置 → 远程实例** 中填写 SSH 命令，或选择本地 SSH 配置中的主机。主机匹配模式需要先补成具体目标。

## 决定由谁启动远程 Yuri

需要 Yuri 安排远程服务时，选择托管连接；目标实例已经运行时，选择外部服务。保存后连接，进度阶段会区分认证、安装启动和转发失败。

连接就绪后确认远程项目目录。窗口虽然在本机，工作空间却在目标电脑。已有 Yuri 主机无需 SSH 也能访问时，直接[配对](/zh-cn/connect-devices/)可能就足够。

## 给其他服务加一条访问路径

实例的端口转发支持 Local（`-L`）、Remote（`-R`）和 Dynamic（`-D`）。Local 把远程服务映射到本机，Remote 反向映射，Dynamic 提供 SOCKS 代理。

仅供本机使用的转发应绑定回环地址。手机需要直接配对远程 Yuri 主机，不会运行桌面 SSH 管理器。

## 一起带上模型配置

已就绪的托管 SSH 连接提供配置同步。向导在所选来源发现 Magpie 后，会显示单独的可选项，用于传输支持的配置和授权。按 [Magpie 传输指南](/zh-cn/magpie/)操作，并在使用前检查目标端结果。
