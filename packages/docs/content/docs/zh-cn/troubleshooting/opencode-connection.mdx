# 界面打开了，工作却开始不了

看见 Yuri 窗口，只证明界面加载成功，不代表 OpenCode 服务或所选模型已经就绪。

## 先读启动阶段的判断

按运行环境安装或兼容性提示处理。CLI 托管查看 `yuri logs`，桌面端查看启动错误和重试操作。`yuri status` 报告的是 Yuri 实例，不能单凭它证明 OpenCode 健康。

默认本地连接使用共享后台服务。重启界面不等于升级或修复该服务。

## 再检查显式覆盖

设置了 `OPENCODE_HOST` 时，确认协议、显式端口，并且没有路径、查询或片段；从 Yuri 主机确认服务真的可达。结合 `OPENCODE_SKIP_START` 和启动日志检查配置是否被拒绝，不要先假定已经连接到目标端点。

## 服务就绪后仍失败

检查会话选中的提供商和模型。提供商登录过期或模型错误，与服务启动是不同问题。重新执行[首次使用](/zh-cn/quickstart/)中的小型只读请求，区分项目访问失败和大型任务自身的问题。
