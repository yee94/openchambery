# 重试 Git 前先检查仓库

先确认当前目录是所连接主机上预期的 Git 仓库。另一台主机中的同名文件夹，是不同的工作副本。

## 看不到 Worktree 操作

项目行的 Worktree 操作要求 Git 项目，普通 VS Code 会话侧栏不提供该入口。支持的界面可以使用项目行操作，或命令面板中的 **New Worktree Draft**。具体位置见 [Worktree 指南](/zh-cn/worktrees/)。

## 创建或分支操作失败

根据错误检查目标分支和路径，关注已有检出目录、重名分支、目录权限以及本地改动。清理前先保留这些改动。Git 创建成功与初始化命令执行失败，是两件不同的事。

## 本地成功，远程失败

在真正执行 Git 的主机上检查远程 URL 和凭据。作者名称 / 邮箱与访问凭据解决不同问题，[身份配置](/zh-cn/git-identities/)应与网络认证分开检查。

在工作文件中解决冲突，再重新执行对应检查。当前 UI 没有 Integrate 或 PR 管理面板可供修复，这些操作请使用 Git / GitHub。
