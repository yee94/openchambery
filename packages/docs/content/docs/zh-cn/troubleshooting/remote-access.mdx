# 沿客户端到主机的路径排查

先看目标电脑：它需要唤醒、联网并运行 Yuri。通过它的实际本地地址或桌面窗口，判断问题是否在网络连接之前就存在。

## 按保存的路由检查

- **局域网：** 客户端需要可达地址，主机需要监听该网络。手机中的回环地址指向手机自己。
- **Relay：** 检查主机是否提供中继及连接状态。只有 Relay 的连接也无法访问离线主机。
- **SSH：** 看失败发生在认证、远程安装启动还是转发，针对该阶段检查，不要反复更换配对码。

## 然后检查设备加入状态

已使用或过期的二维码不能再添加设备，要在正确主机上生成新的。被撤销的客户端必须重新配对；仅在本地删掉连接时，可以使用新的配对重新导入。

能连接却看不到预期工作时，确认主机身份和项目目录。不要因为另一台设备正在查看不同工作空间，就重置主机数据。
