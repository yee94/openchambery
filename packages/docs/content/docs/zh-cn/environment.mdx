# 覆盖主机的启动配置

环境变量作用于读取它的进程。在手机或无关终端设置变量，不会改变已连接的 Yuri 主机。修改启动环境后，需要重启目标进程。

## 调整 Yuri 的访问与存储

| 变量 | 用途 |
| --- | --- |
| `YURI_HOST` | 网页主机的监听地址，扩大监听范围会改变网络可达性。 |
| `YURI_UI_PASSWORD` | 网页界面登录密码。 |
| `YURI_API_ONLY` | 设为 `true` 或 `1`，保留 API，但不提供浏览器界面。 |
| `YURI_DATA_DIR` | 覆盖 Yuri 数据目录，通常为 `~/.config/yuri`。 |

改变数据目录是在选择另一处存储，不会自动迁移旧内容。扩大监听范围时，同时配置访问认证。

## 选择执行环境

| 变量 | 用途 |
| --- | --- |
| `OPENCODE_HOST` | 带显式端口的 HTTP(S) origin，不含路径、查询或片段；优先于 `OPENCODE_PORT`。 |
| `OPENCODE_PORT` | 显式选择 OpenCode 端口。 |
| `OPENCODE_SKIP_START` | `true` 使用不启动托管服务的路径。 |
| `OPENCODE_BINARY` | 显式选择 OpenCode 可执行文件。 |
| `YURI_TERMINAL_SHELL` | Yuri 终端会话使用的 Shell。 |

外部运行环境示例见[主机指南](/zh-cn/opencode-server/)。启动服务已经捕获环境变量时，只修改当前 Shell 不会改变已安装服务。

本页是运维参考，不枚举所有内部构建或调试变量。模型、语音和外观优先使用实际开放的设置控件。
