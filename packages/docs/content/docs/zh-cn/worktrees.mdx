# 给任务一个独立工作目录

Worktree 为同一个仓库提供另一个检出目录和分支。并行工作不应共用一组未提交文件时，使用它。

## 从项目行开始

Git 项目可以使用会话侧栏项目行上的 Worktree 操作，或从命令面板选择 **New Worktree Draft**。手机会话列表的项目行也有对应操作。VS Code 不提供普通项目行上的这个按钮。

选择基础分支，完成草稿。连接 GitHub 后，创建对话框也允许从已有 Issue 或 PR 开始。发送任务前，确认实际目录和分支。

## 明确处理分支的收尾

检查并提交改动后，通过常用 Git 或 GitHub 流程把工作带回目标分支。当前 Yuri 没有已挂载的 Integrate 操作面板。

移除 Worktree 时，仔细区分删除会话、删除目录和删除分支的选项。先保留仍需要的工作，再选择清理内容。
