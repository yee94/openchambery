# 把访问端配对到正确主机

先到存放目标项目的电脑，在 Yuri 的 **设置 → 远程实例** 中，使用连接区域的 **添加设备**。这个页面依赖主机的客户端管理能力，不是 VS Code 设置项。

## 先选访问范围，再生成二维码

配对对话框按主机能力提供本机、局域网和 Relay 选项。本机只用于同一电脑；局域网需要可达的网络地址；Relay 用于网络之外的访问。希望同时保留可用路由时，检查界面提供的回退选项。

命名设备后生成二维码。手机从连接页面扫码，或粘贴配对链接；桌面应用在远程实例中使用 **导入链接**。兑换后才会建立保存的客户端连接，二维码只能使用一次，也会过期。

## 不只检查连上，还要检查连到哪里

连接后打开一个熟悉的项目。连错主机也会表现为「会话不见了」。原生手机应用在 **设置 → 切换实例** 中管理保存的主机，不提供完整的桌面远程实例编辑器。

要取消访问权限，在签发凭据的主机上撤销该客户端。本地移除保存的连接，不等于在主机上撤销凭据。

## 从终端建立配对

在主机运行 `yuri connect-url --port 3000 --qr`，为该实例创建可直连的链接。`yuri connect-url --relay --qr` 则只生成 Relay 链接，要求已有运行且启用 Relay 的主机，不会替你启动。地址和监听选项见命令的 `--help`。浏览器可使用可达的网页地址和登录流程。
