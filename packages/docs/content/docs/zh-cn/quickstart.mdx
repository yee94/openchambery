# 得到第一个有用的回答

第一次运行，选一个不需要大量准备、也不涉及大幅改动的请求。这样更容易判断工作空间是否准备好了。

## 先确定工作位置

在存放文件的电脑上打开 Yuri，添加项目目录；VS Code 使用已经打开的工作区。远程连接时，目录属于远程主机，不属于显示窗口的设备。

进入 **设置 → 提供商**，连接模型提供商。返回对话，选一个可用模型。列表为空时，先完成[提供商配置](/zh-cn/providers/)。

## 给一个能核对的请求

新建会话，尝试发送：

> 检查这个项目的入口，告诉我用哪条命令启动开发，并指出依据来自哪个文件。不要修改文件。

处理出现的问题或权限请求，再打开引用的文件核对回答。这个过程能同时检查模型和项目访问，又不会立即产生改动。

## 然后选择下一步

提出一个小修改并[检查 Diff](/zh-cn/git/)，创建[助理](/zh-cn/assistants/)长期协调工作，或[连接手机](/zh-cn/connect-devices/)继续查看同一个会话。
