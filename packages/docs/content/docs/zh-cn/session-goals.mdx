# 让会话持续推进一个结果

普通消息请求一次回应；目标模式让主机围绕一个结果持续推进多轮。启用前，先写清怎样才算完成。

## 准备、检查，再发送

在项目会话输入框使用 `/goal`。这一步只准备目标模式，不会提交任务。命令后写的目标会留在输入框中，可以继续编辑；检查后发送，才开始执行。

例如：「找出解析器失败的用例，修复后运行对应测试文件，并报告执行命令和结果。」把相关约束写进目标本身。

目标标签仅在已准备或会话已有目标时显示，不是常驻启动按钮。目标界面受聊天设置控制，VS Code 中不提供。

## 看输入框上方的状态条

状态条显示进展、状态和 Token 用量。「评估中」表示主机正在判断是否继续下一轮。通过 **暂停** 中断循环；暂停或阻塞的任务准备好后，再按 **继续**。目标标签上的移除操作可以取消准备状态或清除已有目标。

会话提出问题时，先回答，再检查是否需要继续目标。完成状态也需要结合实际文件和执行结果核对。

## 由主机负责执行

目标循环在主机运行，关闭浏览器标签页不会直接停止它，关闭主机则会。限制或错误可能让任务在完成前停止。需要周期执行时使用[计划任务](/zh-cn/scheduled-tasks/)，不要把单个目标当成定时器。
