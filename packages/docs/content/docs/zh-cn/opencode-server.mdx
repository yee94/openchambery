# 从终端管理 Yuri 主机

本页用于 CLI。桌面应用管理自己的 Yuri 主机，手机连接已有主机。只想访问另一台电脑的工作空间时，从[配对](/zh-cn/connect-devices/)或 [SSH](/zh-cn/remote-instances/)开始。

## 明确正在管理哪个进程

| 命令 | 检查什么 |
| --- | --- |
| `yuri status` | 已登记的 Yuri 实例及其端口。 |
| `yuri logs` | 主机启动和运行消息。 |
| `yuri restart` | 重启 CLI 管理的 Yuri 实例。 |
| `yuri stop` | 停止该 Yuri 实例。 |

希望在当前终端查看启动输出时，使用 `--foreground`。默认本地 OpenCode 连接使用共享服务，停止 Yuri 不代表该共享服务也停止。

## 指向已有 OpenCode 服务

明确管理上游服务时，在启动前配置环境：

```bash
OPENCODE_HOST=http://localhost:4096 OPENCODE_SKIP_START=true yuri
```

地址必须带显式端口，不能包含路径、查询参数或片段。这是在选择 Yuri 背后的执行服务，不是在连接另一个 Yuri 界面。配置被拒绝时，查看启动警告。

## 安排无人值守启动

使用 `yuri startup enable` 启用，`yuri startup status` 检查，`yuri startup disable` 移除。启动服务可以捕获当前环境；启用前先配好需要的值，环境快照选项见 `--help`。

局部覆盖见[环境设置](/zh-cn/environment/)。主机即使正在运行，也仍需有效的模型凭据和可访问的项目目录。
