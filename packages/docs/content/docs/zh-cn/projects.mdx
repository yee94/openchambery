# 选择会话工作的目录

提出涉及文件的请求前，先确认当前项目和连接的主机。Agent 会在这个目录工作；换一台设备打开窗口，不会把文件搬到那台设备。

## 随时能回来的目录

从侧边栏或目录选择器添加项目，再选择项目查看其中的会话。在 **设置 → 项目** 中选择已登记项目，可以调整名称等标识、项目操作和 Worktree 设置。

VS Code 使用编辑器当前工作区，不提供 Yuri 独立的项目设置页。

## 需要时隔离工作

只是在同一目录开展另一段对话，新建普通会话即可。Git 任务需要独立分支和工作目录时，创建 [Worktree 草稿](/zh-cn/worktrees/)。经常执行的 Shell 命令可以保存为[项目操作](/zh-cn/project-actions/)。

## 查看 Agent 的任务清单

Agent 写入待办时，会话状态区和工具结果会显示其进展。这不是用户可编辑的项目清单。[Context 视图](/zh-cn/context/)用于查看对话用量，不存放项目笔记。
