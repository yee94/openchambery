# 离开局域网后继续连接

Relay 是通往已有 Yuri 主机的访问路径，不是另一个运行项目的地方。桌面和 SSH 托管主机可以提供这条路径，普通 Web / CLI 启动不会启用 Relay 主机。

## 先在来源端确认可用

在主机创建支持 Relay 的配对，再从远程实例中检查中继状态。主机和接收设备都需要能访问中继地址。休眠或已经停止的主机，无法通过 Relay 提供服务。

保存的连接同时包含直连与 Relay 时，可以优先使用可达的直连路径。只有 Relay 的链接没有直连回退路径。

## 理解这条路径授予什么权限

中继转发端到端加密流量，设备仍需取得主机授权。加密不意味着尚未兑换的配对密钥可以公开分享。需要取消设备访问时，在主机撤销客户端；不再需要中继路径时，可以停用 Relay。

局域网直连和[公开 HTTPS 托管](/zh-cn/reverse-proxy/)各自有不同的可达性和认证要求。通过[连接检查清单](/zh-cn/troubleshooting/remote-access/)区分是哪条路径失败。
