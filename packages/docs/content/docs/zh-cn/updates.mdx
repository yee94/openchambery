# 更新真正需要更新的组件

桌面和手机提供 **设置 → 关于**。先看版本号对应哪个组件：已安装应用、正在使用的网页包、连接的 Yuri 主机和 OpenCode，不一定是同一版本。

## 按界面提供的更新类型处理

| 应用提供的操作 | 接下来做什么 |
| --- | --- |
| 兼容的 OTA 更新 | 应用后按提示重启或重新加载。 |
| 新桌面安装包 | 完成原生外壳的安装流程。 |
| 手机必须更新原生版本 | 安装当前可用的 iOS 版本或 Android APK。 |

OTA 不能给旧外壳补上缺失的原生能力。更新手机也不会同时更新远程主机。

## 单独决定发布渠道

按需要选择 Beta 更新设置。预发布版本不会因为暂时没有稳定安装包，就变成稳定版。[下载选择器](/#downloads)会标明这种情况，并列出可用平台包。

## CLI 托管的安装

Yuri CLI 使用 `yuri update`，OpenCode 则按所选运行环境的更新提示单独处理。失败时先记下组件和错误再重试，不要把删除项目数据当成客户端更新的修复方式。
