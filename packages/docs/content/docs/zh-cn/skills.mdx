# 给 Agent 一套可复用的方法

任务需要固定流程、支持文件或项目专用指令时，使用 Skill。它补充执行方法，你仍需说明这次要什么结果。

## 使用已经安装的 Skill

打开 **设置 → Skills**，选择条目检查描述、指令和支持文件。用户创建的条目可以编辑，内置条目只读。新建时选择保存位置，以及属于个人还是当前项目。

在项目会话输入 `@`，从引用列表选择 Skill，补充任务后发送。`/` 用于命令选择，不是另一套 Skill 菜单。

## 查找别人发布的方法

桌面或 Web 的 **设置 → Skills Catalog** 是独立设置页面。选择来源、搜索并查看条目，再决定安装位置。通过 **Add catalog** 可以添加其他来源。

专用手机设置导航不提供 Skills Catalog。请从支持的界面安装，再回到所用主机的已安装 Skills 页面查看。

需要连接额外工具而不是提供方法时，配置 [MCP](/zh-cn/mcp/)。
