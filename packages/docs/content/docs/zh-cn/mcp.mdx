# 连接一个工具服务

MCP 条目告诉主机怎样访问额外工具。保存配置、完成认证和建立实时连接，是不同步骤。

## 选对连接形式

在 **设置 → MCP** 添加条目，新建时也可以导入 JSON 片段。设置作用域和传输方式：

- 本地服务填写在主机执行的命令、参数和必要环境变量。
- 远程服务填写 URL，需要时配置请求头或 OAuth。

高级设置提供超时和授权选项。凭据应填在配置字段中，不要贴进任务提示词。

## 验证连接已经准备好

保存后使用条目的连接和测试操作，出现授权要求时完成授权。VS Code 可能要求粘贴授权回调，而不是使用自动建议的回调地址。

认证成功但工具仍不可用时，检查实时连接状态和服务错误。暂时不用可以禁用条目、保留配置；不再需要时再删除。
