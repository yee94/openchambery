# 把运行中的页面放到聊天旁

先确保开发服务正在运行。预览负责显示服务，并不会自行启动你的应用。

## 使用手边已有的入口

| 起点 | 操作 |
| --- | --- |
| 终端输出了被识别的开发地址 | 点击终端中的预览按钮。 |
| 项目操作启动了服务 | 打开该操作的预览，或启用自动预览。 |
| 想输入其他地址 | 打开会话菜单，选择 **打开浏览器面板**。 |

浏览器入口是菜单项，不是标题栏常驻的地球按钮。Electron 直连场景可以使用原生浏览器；Relay 和其他支持的宿主使用预览代理 / iframe 路径。

## 从页面附上依据

对于回环地址上的开发页面，页面连接准备好后，预览工具栏中的检查和控制台操作才可用；任意第三方页面不保证具备这些控件。选择元素或相关控制台输出，附加到当前会话，让 Agent 知道具体对象，而不是只说「那边的按钮」。

远程开发时，确认地址中的 localhost 属于哪台电脑。桌面连接需要本地端口时，可以使用 [SSH 转发](/zh-cn/remote-instances/)。
