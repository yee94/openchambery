# 把对话带在身边

打开原生应用，扫描主机的配对码，或使用已保存连接。**设置 → 切换实例**改变你正在查看的工作空间，不会在主机之间复制项目。

## 从底部标签选择目的地

项目入口通向会话及其结果；助理入口打开联系人对话；计划任务提供任务编辑和运行历史；设置包含手机端开放的配置页面，并非所有桌面设置都在其中。

进入会话后，可以看回复、打开可用的文件改动、处理问题或权限请求。任务仍在主机执行。补充较长要求时，可以使用[语音输入](/zh-cn/voice/)。

### 找到会话，整理列表

在底部选择 **项目**，从项目或 Worktree 下打开会话。左滑会话行可以露出置顶和归档操作；需要经常跟进的会话可以置顶，已经结束的会话可以归档。

### 找助理，查看计划

切到 **助理** 后，点联系人继续对话；切到 **计划** 后，可以查看任务列表，并从顶部切换到历史记录。助理负责对话与协调，计划页用于核对任务安排和实际运行结果。

## 用语音补充要求

启用语音输入后，按住空白输入框开始录音。中间松手会保留可编辑文字，滑向取消区域会丢弃，滑向发送区域会识别后发送。松手前看清高亮目标，尤其留意路径、名称等容易识别错的内容。

## 接收其他应用的材料

把支持的文字、链接或图片分享到 Yuri，再选择助理。Android 将内容放进助理草稿，供检查后发送；iOS 提供分享扩展的确认界面。提交前核对接收对象。

支持的 iOS 安装包还提供系统小组件和实时活动。是否可用取决于原生版本与系统权限，不仅取决于网页包。

## 也可以使用浏览器快捷入口

打开主机网页地址，通过浏览器的安装或「添加到主屏幕」操作创建入口。这仍是使用浏览器权限的网页应用，不会因此获得原生系统集成。功能要求新原生包时，请看[更新说明](/zh-cn/updates/)。
