# 调整阅读外观

打开 **设置 → 外观**。「主题」分组控制明暗模式及各自使用的主题。VS Code 不提供 Yuri 的主题选择控件。

## 决定是否跟随系统

选择固定明亮、固定深色或跟随系统，再为两个模式分别选择主题。修改后检查一段对话和代码块，确认都容易阅读。

## 加载自己的定义

把主题 JSON 放到当前主机 Yuri 数据目录下的 `themes/`，通常是 `~/.config/yuri/themes/`，也可能由 `YURI_DATA_DIR` 指定。随后使用 **外观 → 主题 → 重新加载主题**，再选择加载出的条目。

手机上的重新加载仍然读取主机目录，不读取手机中的文件。JSON 字段见[主题格式参考](https://github.com/yee94/yuri/blob/main/docs/CUSTOM_THEMES.md)。
