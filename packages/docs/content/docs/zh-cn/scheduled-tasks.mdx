# 把任务安排到指定时间

从主导航打开 **计划任务**；手机使用底部对应标签。桌面端会进入任务工作区，不必寻找旧的会话侧栏弹窗。

## 先确定一次执行要交付什么

选择项目并创建任务，填写便于辨认的名称、提示词，以及模型和 Agent 配置。创建需要有可用项目。提示词应包含足够上下文，让新启动的运行不依赖当前聊天也能执行。

在编辑器中设置时间和时区，核对下次执行时间，准备好后启用。只有需要多轮追求结果时，才使用目标执行选项。

## 先运行一次，再交给时钟

使用 **立即运行** 并查看结果。保存成功仅说明配置已经存储，不代表提示词、凭据和工作目录都正确。

在任务工作区的 **历史** 中查看执行记录、耗时和失败原因。有会话的运行可以从那里打开；创建会话之前就失败的记录没有会话链接。计划任务会话归档在普通会话列表之外，应从历史查找。

## 暂停安排，保留依据

暂停任务可以停止后续执行，删除任务不会同时删除运行历史。主机必须保持运行；合上后休眠的电脑不能承担持续调度，也不要假设所有错过的时间都会补跑。
