# 决定 Yuri 何时提醒你

进入 **设置 → 通知**，开启送达，再选择需要提醒的事件：完成、错误、问题、权限请求、子任务、计划任务、助理或目标。

## 按设备确认送达方式

桌面使用系统通知；浏览器有自己的权限和后台推送控制。原生手机应用还依赖安装包、系统权限与连接状态。在 Yuri 中开启某个事件，不会覆盖操作系统的通知设置。

界面提供测试按钮时先测试，再用一次实际事件确认。没有提醒也可能是前台提醒关闭，或系统正在抑制通知。

## 在提供编辑器的界面调整内容

桌面、Web 和 VS Code 提供通知模板编辑。原生手机应用隐藏这部分编辑器和前台提醒控制。请使用实际显示的模板字段；当前 UI 没有消息长度调节项。
