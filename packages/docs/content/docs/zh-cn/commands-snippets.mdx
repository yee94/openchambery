# 把重复请求保存为斜杠命令

经常要求同一类结果时，可以保存为命令。它为 Agent 对话提供指令，与执行 Shell 的[项目操作](/zh-cn/project-actions/)不同。

## 写下能复用的部分

在 **设置 → 命令** 中新建条目，填写名称、作用域和描述，编辑模板，需要时指定 Agent 或模型覆盖。`$ARGUMENTS` 可以接收调用时补充的任务文本。文件引用和命令替换的支持写法，以模板编辑器中的提示为准。

离开前保存。内置命令提供重置操作，不使用用户条目相同的删除方式。

## 在聊天中补上变化的部分

在项目输入框开头输入 `/`，选择命令并补充参数，检查后发送。如果需要的是作为辅助指令加载的方法，请通过 `@` 选择 [Skill](/zh-cn/skills/)。

保留的历史网址中含有 snippets，但当前界面只有命令管理，没有独立的片段管理器。
