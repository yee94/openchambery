# 控制谁能访问工作空间

访问 Yuri 主机，可能进一步触发那台电脑上的文件和工具操作。访问范围和凭据应对应真正需要使用的人与设备。

## 网页登录与配对客户端不同

终端托管的网页界面可以通过 `--ui-password` 或 `YURI_UI_PASSWORD` 设置登录密码。让其他机器可以访问之前，先设置自己的密码。

配对应用使用主机签发的客户端凭据，在主机的远程实例页面管理和撤销。一次性配对链接用于授权设备加入；目标设备兑换前，不要公开尚未使用的链接。

## 添加方便的登录方式

通行密钥入口在 **设置 → 会话** 的 Passkeys 分组。注册取决于浏览器或运行环境支持，以及主机认证配置，不能只凭设备支持生物识别就认定一定可用。

通过已列出的通行密钥和退出登录操作检查访问。注册或全局退出不可用时，阅读具体原因；重置项目文件不能解决认证策略问题。

## 有意识地开放连接

局域网监听、[Relay](/zh-cn/private-relay/)和 [HTTPS 反向代理](/zh-cn/reverse-proxy/)解决的是不同连接问题，都不能替代主机认证。先选择能满足目标设备需要的最小访问范围。
