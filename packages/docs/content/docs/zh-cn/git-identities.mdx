# 确认提交属于谁

作者身份决定提交上显示谁；GitHub 授权决定哪个账号可以访问服务。在个人仓库和工作仓库之间切换时，两者都要检查。

## 看清正在使用的身份

在非 VS Code 界面打开 **设置 → Git**。这里显示全局身份和可编辑的自定义身份。全局条目在此只读；需要不同名称、邮箱或支持的认证配置时，创建或编辑自定义身份。

检查默认选择以及可导入的凭据。给身份起了名字，不代表其凭据就有权访问某个仓库。

## 发布前核对一次

先做一个小的本地提交，在历史中检查作者，再推送。身份正确但远程访问失败时，应单独排查仓库权限和认证，不要反复修改作者名。
