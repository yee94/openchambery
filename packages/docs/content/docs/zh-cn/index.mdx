# 找到你要完成的事

Yuri 的工作空间运行在一台具体的电脑上。桌面窗口、手机和浏览器是访问它的方式。当前连接的主机，决定你能看到哪些文件、会话和助理。

## 从你的情况出发

| 现在的情况 | 接下来做什么 |
| --- | --- |
| 还没运行过 Yuri | [选择安装方式](/zh-cn/install/)，再[发送第一个请求](/zh-cn/quickstart/)。 |
| 工作已经在另一台电脑上运行 | [配对那台主机](/zh-cn/connect-devices/)，或从桌面端建立 [SSH 连接](/zh-cn/remote-instances/)。 |
| 想让一个联系人协助安排工作 | [配置个人助理](/zh-cn/assistants/)。 |
| 想让任务在指定时间执行 | [创建计划任务](/zh-cn/scheduled-tasks/)。 |

## 两种对话入口

**项目会话**展示工作本身：消息、工具执行和文件变化。请求涉及某个目录中的文件时，从对应项目开始。

**助理**提供持续交谈的联系人界面。它可以把工作交给会话，并返回可打开的卡片。具体区别见[助理指南](/zh-cn/assistants/)。

## 任务开始以后

可以在[手机](/zh-cn/mobile/)上看结果，用[语音](/zh-cn/voice/)补充要求，或在提交前[检查改动](/zh-cn/git/)。希望会话在一次回复后继续推进时，可以设置[目标](/zh-cn/session-goals/)。

远程访问和计划执行都需要主机保持可用。切换连接后找不到内容，先检查主机是否正确。[排查指南](/zh-cn/troubleshooting/)会从你仍能访问的部分开始定位。
