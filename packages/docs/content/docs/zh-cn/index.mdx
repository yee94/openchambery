# 从这里开始使用 Yuri

先在存放工作文件的电脑上开始，再连接手机或另一台电脑，随时继续。

## 完成第一次会话

1. 为你的设备[安装 Yuri](/zh-cn/install/)。
2. [连接模型并开始会话](/zh-cn/quickstart/)。
3. [配对另一台设备](/zh-cn/connect-devices/)，继续同一份工作。

## 你想做什么？

- **把工作交给个人助理。** [创建助理](/zh-cn/assistants/)，直接交谈，打开它分配的工作会话。
- **在手机上继续。** [查看回复、审查改动和处理请求](/zh-cn/mobile/)，任务仍在电脑上执行。
- **用说话代替打字。** [开启语音输入](/zh-cn/voice/)，选择先编辑文字，或直接发送。
- **连接远程电脑。** 已运行 Yuri 的电脑用[配对链接](/zh-cn/connect-devices/)；需要从桌面端管理远程服务时用 [SSH](/zh-cn/remote-instances/)。
- **让工作自动执行。** 设置[会话目标](/zh-cn/session-goals/)，或创建[计划任务](/zh-cn/scheduled-tasks/)。

## 工作在哪里执行？

你连接的电脑或服务器负责运行 Yuri 和 Agent 工具。手机应用连接这台主机，不在手机上运行 OpenCode 服务。远程访问和计划任务都需要主机保持唤醒、在线。

项目文件保存在所连接的主机上。切换主机，也会切换你看到的项目、助理和任务。

## 遇到问题

先看[问题排查](/zh-cn/troubleshooting/)；连接不上时看[远程访问检查清单](/zh-cn/troubleshooting/remote-access/)。部署细节和环境变量放在导航的「进阶参考」中，需要时再查。
