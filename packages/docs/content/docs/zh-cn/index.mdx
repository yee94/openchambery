# Yuri 文档

Yuri 是面向编程、个人助理与周期任务的 AI 工作台。把对话、文件、Diff 和终端放在一起，再连接其他设备，随时查看进展并继续工作。

使用本文档来：

- 建立工作空间，选择模型与工具
- 审查 Agent 改动，在其他设备上继续工作
- 把重复工作设为目标或计划任务

## Yuri 用于什么

需要逐步引导时使用普通会话，有明确交付目标时使用目标模式，工作需要重复执行时使用计划任务。Yuri 使用 OpenCode 执行 Agent 任务，提供应用交互、会话协调、设备连接与自动化。计划任务需要 Yuri 服务保持在线。
