# 为设备选择应用

这台设备要负责执行项目，还是连接另一台正在工作的电脑？先确定这一点，再选择安装方式。

## 负责执行工作的电脑

[下载选择器](/#downloads)列出了当前可用的桌面安装包及芯片架构。安装匹配的包并打开 Yuri，桌面应用会启动自己的主机服务，无需另开 Yuri CLI。OpenCode 缺失或需要升级时，按启动页面的提示处理。

如果希望从终端管理主机，先安装 OpenCode，再使用仓库中的安装脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/yee94/yuri/main/scripts/install.sh | bash
yuri --ui-password 'replace-with-your-own-password'
```

换成自己的密码，打开命令输出的地址。后台运行方式见[主机管理](/zh-cn/opencode-server/)。

## 访问工作的设备

同一个下载选择器提供 iOS TestFlight 邀请和 Android APK。安装后需要[配对主机](/zh-cn/connect-devices/)，手机不会运行项目服务器。

浏览器无需安装，直接打开主机可访问的网页地址。编辑器集成则按 [VS Code 包说明](https://github.com/yee94/yuri/tree/main/packages/vscode)安装。

## 选择版本前

同时核对操作系统和 CPU。标有 Beta 的仍是预发布版本，即使它是当前唯一可下载的版本。已经安装过的用户，切换渠道前先看[版本说明](/zh-cn/updates/)。
