# 分清模型访问和 Agent 行为

提供商负责访问资格，模型负责处理请求，Agent 决定工作指令和权限。这三项配置承担不同职责。

## 让模型出现在列表中

进入 **设置 → 提供商**，添加提供商并完成其支持的认证方式，可能是 API 密钥，也可能是授权流程。已连接提供商的详情中可以重新连接或移除访问，模型显隐控制会影响选择列表。

回到输入框，为当前会话选模型。连接账号与选择会话模型，是两个步骤。

使用 Magpie 提供的模型时，先在执行主机上配置其 OpenCode 连接。[Magpie 指南](/zh-cn/magpie/)区分了模型接入、插件登录与用量显示。

## 定义 Agent 怎样工作

在 **设置 → Agents** 创建或选择 Agent。编辑器提供作用域、描述、主 Agent / 子 Agent 模式、模型与变体，以及系统提示词。

权限使用 **允许、询问、拒绝**，支持按模式匹配的规则。需要修改规则时打开高级编辑器；已保存的权限单独检查。宽泛的通配规则会比精确模式影响更多操作。

当前 Agent 编辑器没有温度调节控件，请以实际显示的字段为准。
