# Take the conversation with you

Open the native app and scan a host's pairing code, or use a previously saved connection. **Settings → Switch instance** changes the workspace you are looking at. It does not copy projects between hosts.

## Choose a destination from the bottom tabs

Projects lead to sessions and their results. Assistants open contact conversations. Scheduled tasks provide task editing and run history. Settings contains the mobile configuration pages; not every desktop settings page is included.

Within a session, read replies, open available file changes and respond to questions or permissions. The host continues doing the work. Use [voice input](/voice/) for a longer follow-up instead of typing it on the small screen.

### Find a session and organize the list

Choose **Projects** in the bottom bar, then open a session under its project or worktree. Swipe a session row left to reveal pin and archive actions. Pin work you want to revisit; archive conversations you have finished with.

### Reach an assistant or check a schedule

In **Assistants**, tap a contact to continue talking. In **Schedule**, inspect the task list or switch to **History** at the top. Use the contact conversation to coordinate work and the schedule page to verify its timing and actual runs.

## Speak a follow-up

With voice input enabled, hold the empty composer to start recording. Release in the center to keep editable text, move to the cancel target to discard it, or move to the send target to recognize and send. Check the highlighted target before releasing, especially when the request includes paths or names that may be misheard.

## Bring material from another app

Share supported text, links or images to Yuri and select an assistant. Android places the material in the assistant draft for review and sending; iOS provides a share-extension confirmation screen. Check the destination before submitting.

On supported iOS builds, system widgets and Live Activities provide additional entry and status surfaces. Their availability depends on the installed native version and system permissions, not just the web bundle.

## If you prefer a browser shortcut

Open the host's web address and use the browser's installation or Add to Home Screen action. This is a browser installation with browser permissions; it does not acquire the native app's system integrations. See [updates](/updates/) when a feature requires a new native build.
