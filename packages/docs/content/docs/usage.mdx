# Read account usage in context

Open **Settings → Usage** and choose an account or provider. This view reports supported account quotas; it is not the same as a session's [context usage](/context/).

## Decide what to keep visible

The settings sidebar offers refresh controls, automatic refresh timing and display preferences. Account details expose **Show in header** where supported, so selected information can be reached from the header without reopening Settings.

Read the quota window and reset information together with the value. A number without its time window can be misleading.

The sidebar's **Magpie** group discovers supported gateways on the connected host and offers **Connect another Magpie** for an explicit address. See [Magpie usage and integration](/magpie/) for account aggregation and remote-access requirements.

## Distinguish missing data from no usage

Provider support and authentication determine which details can be retrieved. An unavailable or failed fetch does not prove that the account has no remaining credit. Check the reported error and reconnect the provider if necessary; use the provider's own account page when the value is not supplied here.
