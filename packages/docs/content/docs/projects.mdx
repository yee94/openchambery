# Choose where a session works

Before sending a file-related request, check the selected project and connected host. The Agent works in that directory; changing the window's device does not move the files.

## A directory you can return to

Add a project through the sidebar or directory picker, then select it to see its sessions. **Settings → Projects** lets you select a registered project and adjust its identity, project actions and worktree settings.

In VS Code, the editor's open workspace supplies the project. Yuri's separate Projects settings page is not offered there.

## Keep work separate when needed

Use an ordinary new session for another conversation in the same directory. For a Git task that needs an isolated branch and checkout, create a [worktree draft](/worktrees/). Save repeatable shell commands as [project actions](/project-actions/).

## Read the Agent's task list

When an Agent writes todos, Yuri displays them in the session's status area and tool results. These reflect the Agent's progress; they are not a user-editable project checklist. The [Context view](/context/) reports conversation usage rather than storing project notes.
