# Connect a tool service

An MCP entry tells the host how to reach extra tools. Saving an entry, authenticating it and establishing a live connection are distinct steps.

## Choose the right connection form

In **Settings → MCP**, add an entry or import a JSON snippet when creating one. Set its scope and transport:

- A local service needs the command and arguments that run on the host, plus any environment variables.
- A remote service needs its URL and, where required, headers or OAuth configuration.

Advanced settings expose timeout and authorization options. Keep credentials in the configuration fields rather than pasting them into a task prompt.

## Prove the connection is ready

Save, then use the entry's connection and test controls. Complete authorization if requested. VS Code may require pasting the authorization callback instead of using an automatically suggested redirect.

If authentication succeeded but tools remain unavailable, inspect the live connection status and service errors. Disable an entry to stop using it without deleting its configuration; remove it when it is no longer needed.
