# Understand a conversation's size

The context indicator describes the conversation being sent to the model. It is different from a provider's account quota, which belongs in [Usage](/usage/).

## Open the numbers behind the indicator

On desktop, click the usage ring in the header. You can also run **Show context usage** from the command palette. The Context panel shows the percentage used, message count and available token, cost and throughput details.

Treat the displayed numbers as reported or derived usage, not as a promise about remaining subscription credit. Available details depend on the model's responses.

## When the conversation gets large

Check whether the current request still needs the earlier discussion. Use the session's compaction operation when you want to retain a summary, or begin a new session with a concise handoff for a different task. Keep important requirements explicit rather than relying on distant messages.
