# Pick the app for your device

Will this device run your projects, or connect to a computer that does? That choice matters more than the size of its screen.

## A computer that runs the work

The [download chooser](/en/#downloads) lists the available desktop installers and their processor architectures. Install the matching package and launch Yuri. The desktop app starts its host; a separate Yuri CLI process is unnecessary. Follow the startup screen if OpenCode needs installation or an upgrade.

For a terminal-managed host, install OpenCode and use the repository's installer:

```bash
curl -fsSL https://raw.githubusercontent.com/yee94/yuri/main/scripts/install.sh | bash
yuri --ui-password 'replace-with-your-own-password'
```

Use your own password and open the address printed by the command. [Host management](/opencode-server/) covers background operation.

## A device that connects to the work

Use the same download chooser for the iOS TestFlight invitation and Android APK. These apps need a [pairing connection](/connect-devices/); they do not run a project server on the phone.

A browser needs no installer: open the host's reachable web address. For editor integration, follow the current [VS Code package instructions](https://github.com/yee94/yuri/tree/main/packages/vscode).

## Before selecting a release

Match both the operating system and CPU. A Beta label means a prerelease, even when it is the only download available. Consult [release channels](/updates/) before changing an existing installation's channel.
