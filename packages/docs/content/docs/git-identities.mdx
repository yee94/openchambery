# Check who a commit belongs to

An author profile answers who appears on a commit. GitHub authorization answers which account can access the service. Check both when moving between personal and work repositories.

## Inspect the effective profile

Open **Settings → Git** outside VS Code. The page displays the global identity and editable custom profiles. The global entry is read-only here; create or edit a profile when you need a different name, email or supported authentication configuration.

Review the selected default and any credentials offered for import. Naming a profile does not establish that its credentials can access a particular repository.

## Verify before publishing

Make a small local commit and inspect its author in history before pushing. If the profile is correct but remote access fails, investigate repository permissions and authentication separately rather than changing the author name repeatedly.
