# Change the instructions behind an action

Use **Settings → Magic Prompts** when an existing action produces the wrong style or emphasis. This page is available outside VS Code and organizes templates into Git, GitHub and Session groups.

## Edit the part that matters

Choose the relevant action. Where a template separates visible text from instructions, keep their roles distinct: the visible text appears as the request, while the instructions guide execution. Preserve named placeholders used to insert real task data.

Save the override and try the action on a small example. A template's presence here is not proof that every older action using it still has a visible launch button.

## Recover the original behavior

Reset the selected template to remove its override. Use the all-overrides reset only when you intend to discard every customization on this page.
