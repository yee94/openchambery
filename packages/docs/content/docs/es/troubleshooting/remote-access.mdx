# Acceso remoto

Cuando no puedes alcanzar Yuri desde tu teléfono u otra máquina, la solución depende de cómo te estés conectando.

## Comprueba lo básico primero

- abre `http://localhost:3000` en la misma computadora primero; si eso falla, no es un problema remoto; consulta [Conexión de OpenCode](/es/troubleshooting/opencode-connection/)
- confirma que el servidor está en funcionamiento con `yuri status`

## Un dispositivo vinculado no se conecta

- el código QR / enlace de vinculación es **de un solo uso**; si ya se escaneó (o caducó), crea uno nuevo desde **Añadir un dispositivo**
- si el dispositivo se vinculó con **Solo red doméstica**, no puede conectarse desde fuera de esa red; vuelve a vincularlo con **En cualquier lugar**
- para la vinculación **En cualquier lugar**, comprueba **Settings → Remote Instances → Yuri Relay** en el servidor: debería decir **Conectado**; si no, desactívalo y vuelve a activarlo
- si un dispositivo fue **revocado**, su token desaparece para siempre; vincúlalo de nuevo con un código QR nuevo

Consulta [Conectar un dispositivo](/es/connect-devices/) y [Private Relay](/es/private-relay/) para saber cómo funcionan estas conexiones.

## La instancia remota no se conecta (escritorio)

Cuando una [instancia remota](/es/remote-instances/) se atasca, Yuri nombra el paso que falló:

- **auth** — tu contraseña de SSH o de UI fue rechazada; vuelve a introducirla
- **install / start** — Yuri no pudo configurar o iniciar el servidor en la máquina remota; comprueba los requisitos de esa máquina
- **forwarding** — la conexión está activa pero el puerto no te llega; prueba un puerto local distinto

## Detrás de tu propio servidor

Si pones Yuri detrás de un proxy inverso y carga de forma extraña o no se conecta, consulta [Proxy inverso](/es/reverse-proxy/).
