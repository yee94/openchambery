# Yuri Docs

Yuri is an AI workspace for coding, personal assistants, and recurring tasks. Keep conversations, files, diffs, and terminals together, then connect another device to follow the work wherever you are.

Use these docs to:

- set up a workspace and choose models and tools
- review agent changes and continue work from another device
- turn repeatable work into goals and scheduled tasks

## What Yuri is for

Use interactive sessions when you want to guide each step, goals when you have an outcome to pursue, and scheduled tasks when the work repeats. Yuri uses OpenCode for agent execution and provides the application, session coordination, device connectivity, and automation around it. Scheduled tasks run while the Yuri server is online.
