# Make yourself at home

Start on the computer where your work lives. Connect your phone or another computer when you want to continue elsewhere.

## Your first session

1. [Install Yuri](/install/) for your platform.
2. [Connect a model and start a session](/quickstart/).
3. [Pair another device](/connect-devices/) to pick up the same work.

## What would you like to do?

- **Give work to a personal assistant.** [Create an assistant](/assistants/), talk to it, and open the sessions it assigns.
- **Continue on your phone.** [Read replies, review changes and respond](/mobile/) while your computer does the work.
- **Speak instead of typing.** [Set up voice input](/voice/) and choose whether to edit or send the result.
- **Connect a remote computer.** Use a [pairing link](/connect-devices/) for an existing Yuri server, or [SSH](/remote-instances/) from the desktop app.
- **Run repeatable work.** Set a [session goal](/session-goals/) or create a [scheduled task](/scheduled-tasks/).

## Know where your work runs

Your connected computer or server runs Yuri and the Agent tools. The mobile app connects to that server; it does not run a local OpenCode server. Keep the host awake and online for remote access and scheduled work.

Project files belong to the connected host. Switching hosts changes which projects, assistants and tasks you see.

## Need a hand?

Start with [troubleshooting](/troubleshooting/). For connection problems, use the [remote access checklist](/troubleshooting/remote-access/). Deployment details and environment variables are under **Advanced reference** in the navigation.
