# Get one useful answer

For a first run, use a request that does not depend on a long setup or a large code change. It gives you a clear way to tell whether the workspace is ready.

## Prepare the destination

Open Yuri on the computer containing your files. Add the project directory, or use the workspace already open in VS Code. On a remote connection, the directory belongs to that host, not the device displaying the window.

In **Settings → Providers**, connect a model provider. Return to the conversation and select an available model. If the list is empty, finish the [provider setup](/providers/) first.

## Make the request easy to verify

Create a session and ask:

> Inspect the project entry points. Tell me which command starts development and cite the file where you found it. Do not edit anything.

Answer any question or permission request. Check the cited file against the reply. This tests access to both the model and the project without committing you to a change.

## Decide what comes next

Ask for a small modification and [review the diff](/git/), create an [assistant](/assistants/) for ongoing coordination, or [connect your phone](/connect-devices/) to follow this same session elsewhere.
