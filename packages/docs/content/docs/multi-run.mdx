# Compare runs in VS Code

The currently reachable group-creation interface is the VS Code Agent Manager. Desktop and Web do not expose the former sidebar multi-run launcher.

## Launch from the editor

Open a Git workspace in VS Code and run **Yuri: Agent Manager** from the editor's command palette. Create a group with a name, task prompt, base branch and selected models. The form accepts up to five model runs and offers an Agent selection and worktree setup commands.

The group uses the editor workspace. Check the prompt and branch before creating the runs, especially when setup commands modify files or install project dependencies.

## Compare the resulting work

Select the created group to inspect its runs. Each run has its own session and checkout. Compare the outputs and changes against the same acceptance criteria; choosing a favorite answer does not itself merge its branch.

Use your usual review and Git workflow to keep the result you want.
