# Підключення до OpenCode

Якщо Yuri завантажується, але ніяк не виходить за межі стану «OpenCode перезапускається», або чат не відповідає, сервер, із яким він спілкується, недоступний. Пройдіться по цьому.

## Він застряг на «OpenCode перезапускається»

- дайте йому хвилину одразу після запуску — цей стан нормальний, поки сервер стартує
- перевірте, чи сервер живий, командою `yuri status`
- перезапустіть його командою `yuri restart`
- перегляньте деталі запуску командою `yuri logs`

## Ви підключаєтеся до власного сервера

Якщо ви налаштували Yuri на використання наявного сервера, ще раз перевірте налаштування з [OpenCode Server](/uk/opencode-server/):

- `OPENCODE_HOST` має містити порт, без шляху — наприклад, `http://localhost:4096`
- задайте `OPENCODE_SKIP_START=true`, щоб Yuri не запускав ще й свій
- якщо адреса недійсна, Yuri ігнорує її й натомість запускає власний сервер — шукайте попередження `[config]` у журналах

## Усе ще не працює

- переконайтеся, що версія Node.js — `20` або новіша
- перевстановіть найновіший CLI
- відкрийте `http://localhost:3000` напряму
