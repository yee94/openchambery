# Check the repository before retrying Git

First confirm the selected directory is the intended Git repository on the current host. A folder with the same name on another host is a different working copy.

## No worktree action is visible

The project-row worktree action requires a Git project and is not provided in the ordinary VS Code session sidebar. On supported surfaces, use that project action or **New Worktree Draft** from the command palette. See [worktrees](/worktrees/) for the current entry points.

## Creation or a branch operation fails

Read the error for the requested branch and path. Check for an existing checkout, a conflicting branch name, directory permissions and local changes. Preserve those changes before attempting cleanup. A failed setup command is separate from Git successfully creating the checkout.

## Local work succeeds, remote work fails

Check the remote URL and credentials on the host performing the Git operation. Author name/email and access credentials solve different problems. Verify the [identity profile](/git-identities/) separately from network authentication.

Resolve conflicts in the working files and rerun the relevant check. The current UI has no Integrate or PR-management panel to repair; use Git/GitHub for those operations.
